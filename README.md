# Audiobooster Supported Packages Registry

Curated key-value registry of supported audio player apps for Audiobooster, mapping Android package identifiers to their display names.

## Supported Apps Mapping (`supported_packages.json`)

The supported package mapping is maintained in [`supported_packages.json`](supported_packages.json):

```json
{
  "com.spotify.music": "Spotify",
  "com.google.android.apps.youtube.music": "YouTube Music",
  "com.sec.android.app.music": "Samsung Music"
}
```

This curated mapping is separate from the live user-reported package registry. A user report alone does not independently verify playback compatibility.
